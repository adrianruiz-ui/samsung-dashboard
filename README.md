# samsung-dashboard
Dashboard de performance — redes sociales Samsung MX

## Páginas
- `index.html` — dashboard maestro (raíz del sitio).
- `mapa.html` — mapa de campañas: grafo de posts por campaña con lentes de KPI (VTR ≥ 25% en videos de 0–30 s; ER básico IG ≥ 5% en feed). Lee el Sheet ÚLTIMA en vivo con el mismo acceso @ganem.mx del dashboard.
