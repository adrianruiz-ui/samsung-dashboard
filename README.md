# samsung-dashboard
Dashboard de performance — redes sociales Samsung MX

## Páginas
- `index.html` — dashboard maestro (raíz del sitio).
- `mapa-3d.html` — mapa de campañas: árbol 3D de los posts contra los KPIs (VTR ≥ 25% en videos de 0–30 s; ER básico de todas las plataformas, con meta de 5% solo en IG), con filtros, línea de tiempo y viaje de producto. Lee el Sheet ÚLTIMA en vivo con el mismo acceso @ganem.mx del dashboard.
- `graficas.html` — gráficas de desempeño: flujo del alcance (pauta → plataforma → formato → campaña), ola semanal, el año en espiral y duración contra retención. Mismo acceso y filtros que el mapa.
- `mapa.html` — redirige a `mapa-3d.html` (la versión plana se retiró).

> **Al subir una versión nueva de `index.html`:** parte de la versión que está en `main`. El encabezado y la barra lateral tienen los accesos a `mapa-3d.html` y `graficas.html` (marcados con «NO QUITAR»); si se sube una copia anterior, desaparecen.
